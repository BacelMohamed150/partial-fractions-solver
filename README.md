I got this idea when I was solving this kind of integration:
$$\int \frac{1}{x^n + 1} \, dx$$

At the same period, I was learning how to solve this linear system: 
$$\mathbf{A}\mathbf{x} = \mathbf{b}$$

along with the basics of NumPy and SymPy. However, the more I solved these integrals, the more I wondered: what if I wanted to solve one with $n = 6$ or $7$? How could I solve it without manually finding the unknowns of partial fractions? 

So, I wrote this code to help me with this task, and I am planning to improve it soon.
